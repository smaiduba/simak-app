Import Data Siswa

Melengkapi biodata berdasarkan nama siswa + nama ayah. Nomor induk database tidak akan diubah.

Sebelum memulai

Gunakan file Excel (.xlsx/.xls) atau CSV. Baris pertama harus berisi judul kolom. Nama siswa dan nama ayah wajib ada. Import hanya memperbarui siswa yang cocok dengan data di database. Siswa yang tidak ditemukan tidak akan ditambahkan. Nomor induk tidak akan diubah dan data kosong dari file tidak akan menghapus nilai lama. Maksimal 1.000 baris per proses.

Belum ada file yang dipilih.

2. Petakan kolom file

Kolom dipetakan otomatis jika judulnya dikenali. Pastikan Nama Siswa dan Nama Ayah benar.

3. Tinjau hasil pencocokan

Hanya siswa yang cocok secara unik dengan database yang dapat dipilih. Baris tidak ditemukan, ambigu, duplikat, atau tidak lengkap akan dilewati.

Import Nilai Akademik

Pencocokan ganda: nomor induk + nama siswa. Hanya memperbarui nilai pada DataNilai.

Aturan keamanan

File harus memiliki kolom nomor induk dan nama siswa. Sistem hanya memperbarui baris DataNilai jika kedua identitas cocok. Siswa tidak ditemukan tidak akan ditambahkan. Kolom nomor induk dan nama tidak ditulis saat simpan. Sel kosong di file diabaikan sehingga nilai lama tidak terhapus. Maksimal 1.000 baris per proses.

Belum ada file yang dipilih.

Centang hanya jika kolom nilai di file memang berada pada posisi kolom yang sama. Jika berbeda, biarkan tidak dicentang dan petakan kolom satu per satu.

2. Petakan kolom file

Pilih sumber nomor induk, nama siswa, serta kolom nilai yang akan dimasukkan ke DataNilai. Kolom yang tidak dipetakan akan diabaikan.

KolomJudul kolom fileFungsi / kolom tujuan

Hanya baris dengan nomor induk dan nama yang cocok secara unik dapat dipilih. Baris mismatch, tidak ditemukan, ambigu, duplikat, atau nilai tidak valid akan dilewati.
